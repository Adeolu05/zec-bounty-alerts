## CanIShield Deposit Checker

**Description:**
A simple web tool that allows you to check whether a given ZEC address can receive deposits via the CanIShield service. This helps users quickly verify address compatibility before attempting a transaction.

**Live Demo:** https://canishield.vercel.app/

---

## AmILinkable Checker

**Description:**
This utility checks if a ZEC address is *linkable*, i.e., whether it can be associated with a shielded transaction. Useful for privacy‑focused workflows and ensuring address suitability.

**Live Demo:** https://am-i-linkable.vercel.app/
